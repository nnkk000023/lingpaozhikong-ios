GETTING STARTED

快速克隆与真机运行

无需配置复杂第三方依赖，打开 Xcode 即可运行；内置离线完整体验模式，无账号也能立刻上手。

STEP 01

克隆仓库并打开工程

需要 macOS 14+ 与 Xcode 16+（若首次编译 Metal 着色器提示缺少工具链，请先下载 MetalToolchain）。

git clone https://github.com/nnkk000023/lingpaozhikong-ios.git
cd lingpaozhikong-ios
open Lingpao.xcodeproj
STEP 02

配置个人 Apple ID 签名

在 Xcode 分别选中 LingpaoApp 与 LingpaoWidgets，设置你的个人 Team 与同前缀 Bundle ID，并核对 App Group。

# 验证核心包单元测试（5 大套件全覆盖）
cd LingpaoCore
swift test
STEP 03

三种无门槛体验 / 登录方式

支持「离线体验模式」直接把玩 12 款车型与 Metal 渲染；亦支持导入原始 Auth 凭据或手机号 + 极验 v4 登录。

# 增删文件后一键重建工程
DEVELOPER_DIR=/Library/Developer/CommandLineTools \
  python3 Scripts/generate_xcodeproj.py
